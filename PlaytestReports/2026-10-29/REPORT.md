**วิธีทดสอบและข้อจำกัด**

ใช้ Unity 6000.5.10f1 ผ่าน Unity MCP/API เท่านั้น สังเกต/ตัดสินใจประมาณทุก 120 ms คุมขนาด Gum แถว 48–86% และตอบสนองต่ออุปสรรค/เส้นเตือนที่อยู่ในกรอบกล้อง จอแดงส่งการแตะประมาณ 5.9 ครั้งต่อวินาทีหลังเวลาตอบสนองราว 0.22 วินาที จอฟ้าปล่อยปุ่มตามกติกา ไม่ปรับ seed ของเกม ไม่ teleport ไม่แก้ความเร็ว ดาเมจ เป้าหมาย mash หรือตาราง spawn

Input legacy ไม่รับปุ่มจาก GameView input API ใน preflight จึงเพิ่ม Func<bool> รับปุ่มทดสอบชั่วคราวที่จุดอ่านปุ่มของ Event ใช้ UpdateRedEvent/UpdateBlueEvent และผลลัพธ์เดิมทั้งหมด ตัว Player รับ SetBlowInput ผ่าน API ปกติ ข้อมูลขนาด Gum และตำแหน่งที่อ่านได้ตรงจาก API ให้ความแม่นกว่าผู้เล่นมนุษย์ จึงไม่ควรเทียบจำนวนชนหรือเวลาจบกับผู้เล่นคนแรกโดยตรง

หลังจบคืนไฟล์ PanicEventManagerVariantNoStop.cs จากสำเนาก่อนทดสอบและตรวจ SHA-256 ตรงกันทุก byte ไม่มีตัวรับปุ่มทดสอบเหลือใน source ที่ใช้งาน ไม่แก้เกมเพื่อแก้ข้อค้นพบในรายงานนี้
